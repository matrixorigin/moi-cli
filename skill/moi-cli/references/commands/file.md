# file command reference

Generated from CLI source. Do not edit. Business requirements remain server-owned.
Use `moi-cli schema DOMAIN COMMAND` for typed JSON input and `--help` for defaults.

## file list

- `--extensions`: Comma-separated file extensions without dots
- `--file-ids`: Comma-separated File IDs
- `--name`: File name fragment
- `--page-size`: Page size (1-100)
- `--page-token`: Next page token
- `--workspace-id`: Workspace ID (default: from config or MOI_WORKSPACE_ID)
