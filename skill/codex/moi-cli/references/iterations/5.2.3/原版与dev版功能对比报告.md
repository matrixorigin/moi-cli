# 原版与 dev 版功能对比报告

> 版本说明：本报告完整保留 0.4.12 内容基线的验收结果；5.2.3 进行仓库化与命名统一，未把基线结果冒充本轮新增线上验收。

## 对比口径

稳定侧仍是原版 CLI 0.1.8 + Skill 0.3.25；当前侧是 dev CLI `0.1.0-dev.d5c5c3a` + Skill `0.4.12`。本版没有重跑稳定版、原 dev 的 125/151 场景或新增线上功能点，以下只比较可靠性和合同完整性。

| 范围 | Skill 0.4.11 | 当前 dev + Skill 0.4.12 | 变化 |
| --- | --- | --- | --- |
| 全部 308 项 | 123 通过、115 部分通过、59 缺条件、10 CLI 缺口、1 失败 | 与左侧相同 | 不虚增产品通过数 |
| 当前 CLI 工作范围 | 141 项：123 通过、14 Bug、4 疑似、0 待补 | 与左侧相同 | 工作范围不变 |
| GA 251 项 | 109 通过、99 部分通过 | 与左侧相同 | 无新增线上验收 |
| 复杂任务模板 | 依赖 Recipe 人工组织 | 3 套任务模板、17 步、依赖和验收条件内置 | 更容易重复执行和接续 |
| 恢复与防重 | `task_run` 有一次主调用保护 | 新增只读恢复判断，未知/未验收状态明确阻止继续 | 防重提示更直接 |
| 文件输入证据 | JSON/SQL和少量上传文件 | 15 结构化、3 原始输入、3 输出；凭证文件明确拒绝 | 覆盖 Workflow/Knowledge 常用输入 |
| 默认 CLI | 未设环境变量时可能指到稳定版 | 固定 dev 默认路径，可用正式变量显式覆盖 | 避免误用版本 |
| 缺口管理 | 分散在报告和场景记录 | 35 项统一机器清单、help 校验、禁止替代路径 | 不再猜参数 |
| 本地可移植性 | macOS `/var`、`/tmp` 可能无法保存证据 | 目录别名先解析，最终文件仍禁止链接 | 临时目录可用且边界不变 |

## 没有变好的地方

- 35 个合同缺口仍是缺口，本版只是把它们明确、可检查地呈现出来，没有伪造正式入口。
- 任务模板不会自动判断线上资源是否存在，也不会自动获得上传、运行、删除或权限变更授权。
- 恢复检查只保证本地防重决策，不能证明远端没有接受请求；未知提交仍须用真实对象 ID 查询。
- 原有 14 个较明确 Bug、4 个疑似 Bug、普通成员/外部连接等缺条件均保持原结论。

稳定版回退不受影响。本版只更新 `moi-cli-dev` 的工具、规则、证据和分发包，没有修改 CLI 或后端。
